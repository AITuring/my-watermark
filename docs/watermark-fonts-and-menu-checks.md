# 水印工作台与字体来源

桌面底栏通常为 72px；768–950px 窗口使用 128px 两行布局，避免输入框、开关和导出被挤掉。底栏包含水印类型、标题/说明、排版方向、背景模糊、统一设置、编辑范围和导出。字体排版、智能适配、外观位置及导出参数移入右侧设置面板，打开时为面板预留空间。编辑范围与预览里的批量开关同步；透明度、背景模糊、模式、智能适配开关与质量为全局设置。内容、字体、颜色、大小、位置按当前或全部图片操作。导出按钮始终导出全部图片，等待最新预览，使用请求锁避免重复任务。多张图片打包成一个 ZIP，避免浏览器拦截连续下载；重名图片在包内自动加序号，不覆盖。

背景模糊常驻桌面和手机底栏，设置面板不再重复提供。横竖排在底栏、设置面板和手机共用 `WatermarkDirectionSwitch`：两端保留横排／竖排文字，中间使用与背景模糊相同的圆形滑块 `Switch`，支持点击任一方向文字及空格切换。方向和单列／双列等方案的语义及记忆规则不变；辅助线、批量编辑也使用标准尺寸的圆形开关。浏览器核对了桌面／手机状态同步、模糊开关、键盘方向切换和 900px 底栏无溢出。

桌面左侧图片列表由原先窗口宽度的 24% 改为固定 128px，收起后为 40px。两种状态都可添加、切换图片；展开时保留清空入口，并在缩略图悬停或键盘聚焦操作按钮时显示预览、移除。缩略图统一 `object-fit: contain`，不裁切原图或缩略图内容。图片高亮跟随主编辑器的当前图片。左右留白与栏间距均为 12px；1280px 浏览器实测中间预览区为 1116px，收起左栏后为 1204px。已核对展开／收起、迷你栏切图与大图预览；共享图片选择器其他页面默认仍显示原有表头。

在线目录固定版本，详见 `src/pages/watermark/fonts/catalog.json`；97 款内置字体直接使用真实字形的本地 PNG 预览，打开即显示，不依赖远程字体下载。原有预览由实际字体渲染“永和九年”，生成工具见 `scripts/fixtures/watermark-font-previews.html`；新增本地字体的预览由 `scripts/prepare-local-watermark-fonts.py` 生成，古文字字库缺少样张用字时选用该字库实际包含的汉字。字体元数据和样张字形子集由 `scripts/prepare-watermark-fonts.py` 固定版本打包。选用字体时按正文 Unicode 覆盖加载所需子集，并发上限 4，支持 Cache Storage 缓存和延迟 180ms 的镜像竞速；同一图片的标题和说明统一字体。加载失败保留原选择，可重试。字体缺字时明确提示哪些字用系统宋体补齐。导入 TTF/OTF/WOFF/WOFF2 文件不上传，仅在本次页面会话有效。

## 预览文字原位编辑

文字及图文模式下，点击／轻触预览中的标题或说明，会在对应位置打开透明的原生文字输入框，无底色、边框和阴影，保留水印字体、字号、颜色及透明度；编辑时临时隐藏对应的底层文字，避免新旧文字重叠，图标和另一行文字继续显示。支持横排、竖排和预览缩放。Enter 确认，Esc 取消，点击外部或移出焦点保存；中文输入法选词时的 Enter 不提交编辑。修改按当前／全部图片范围应用，底栏文字和导出配置同步更新。按住拖动仍移动水印，点击图标仍显示变换控件。

开发服务器下打开 `/scripts/fixtures/watermark-inline-edit.html` 可复查点击命中、键盘确认／取消、点击外部保存、拖动和缩放。`node --test scripts/test-watermark-fonts.mjs scripts/test-watermark-filename.mjs` 包含文字区域与实际渲染布局一致性的检查。

文件名按“时代-作者（可省略）标题-馆藏-备注（可省略）-原始照片名”解析。馆藏作为标题范围的边界；馆藏之后的所有备注、处理说明和原始照片名不进入标题。作者可与书名号标题连写，也可单独用连字符分隔；无书名号且与标题连写的作者，以常见作者前缀识别。主标题保留作品名称及其书名号、墓室壁面等名称上下文，说明格式为“时代·作者·馆藏 / 摄影署名”，缺失字段省略。

## 设置内的横竖排方案与简化字体面板

桌面“设置 → 排版”和手机“水印”面板共用方案选择器。横排提供单行横署、两行并置、三行居中；竖排只提供单列、双列。横竖方向分别记忆方案，切换方向不清除另一方向的选择；手动选择优先于智能方向。纯文字模式不绘制图标，居中方案对应两行文字居中。

同组标题与说明使用同一字体、同一字号。横排单行的图案与文字可见字高齐平；两行并置的文字左对齐，图案等于两行总高；三行居中让图案独占上行，共用中轴。竖排小印始终在全部文字上方，双列标题在右、说明在左且顶端对齐，小印高度最多 1.5 个字号，不随列宽拉大。图文模式取消独立图案比例滑块，避免破坏已约定的对齐关系。默认字距 10%、行列间距 55%，按字号计算；预览与导出共用可见字形边界和同一个渲染器。

字体面板只显示“全部、书法、宋体、其他”四个分组，保留搜索字体名／书法家／书体和本地导入。当前字体与默认宋体优先显示；点击字体成功加载后直接应用并关闭，无额外确认步骤。缺字或加载失败仍保留提示。移除重复的名家推荐区和多层分类，来源与许可入口仍可查看。

本轮浏览器验证了方向分别记忆、字体搜索及点选关闭、390×844 手机面板、横竖排透明原位编辑与 Enter／Esc。正式编辑器导出的两张完整画面测试副本经 ZIP 解码核对，尺寸仍为 2000×799、1250×2000；测试副本来自完整原图缩小预览，未进一步裁切，不能据此视作超大原分辨率验收。主体识别的限制仍见下文“完整素材试排与主体避让”。

## 统一字体、标识与原图尺度

同一图片的标题和说明统一字体，桌面与移动端均提供一个字体选择器。智能适配依据文件名中的作者和作品类型选择已收录字体；已知作者优先对应字库，普通书画回退赵孟頫楷书，造像、青铜及未知类型回退方正细金陵简体。此规则依赖文件名证据，不是图像分类或书风鉴定；手动字体优先，关闭智能适配后保留指定字体。批量预览和导出使用同一规则。

纯图案模式使用 `/logo.png` 的图形与下方署名组合；图文模式使用用户提供的纯图形 `/watermark-symbol.png`。尺寸先按原图像素和长宽比估算，可靠的原画参考字高可覆盖估值；说明和署名字号随主标题同比变化。`referenceTextHeight` 已支持配置，但尚无可靠的自动 OCR 字高输入。

## 多背景适配回归

脚本样例 `scripts/fixtures/watermark-color-cases.js` 覆盖 20 类背景：纸色、黑白/灰、冷暖与高饱和色、棋盘、冷暖拼接、渐变、墨纹、彩色花纹、云层、织物及透明区域。`watermark-color-matrix.html` 检查固定区域的单色局限，`watermark-color-placement.html` 运行真实文字渲染、自动方向、位置与颜色的完整流程。

## 切图与大图预览地址生命周期

复现：保留已导入图片时触发页面 Fast Refresh，再选择另一张图，原先卸载清理会撤销列表仍持有的 Blob URL；主画布空白，大图预览 naturalWidth 为 0，尺寸仍显示上一张。现改为延迟释放并在 effect 重新连接时取消释放；删除图片立即释放对应 URL，真正离开页面后释放剩余 URL。遇到此前已经失效的地址，从保留的 File 重建预览，并同步列表与当前图片，保留 ID、编辑参数及原文件。HTTP 大图服务地址不由 Blob URL 管理器释放。

大图预览按当前图片地址隔离尺寸和大小元数据，切换时取消旧请求；Blob 大小读取响应头，不重复读取整张文件，也不发送 Blob URL 不支持的 HEAD 请求。加载失败提供可见提示。新增 3 项回归覆盖 24 个 URL 的 effect 清理重连、移除/切换释放边界、失效恢复；与原有 49 项共 52 项通过。浏览器用 24 张完整画面预览素材验证热更新、连续横竖图切换与弹窗预览；验证素材最长边为 2000px，本轮未重新验证原始超大文件导出。

## 整个预览区缩放

画布宽高现与预览容器一致，图片在画布内居中。进入或切换图片时，完整画面按原始宽高比适应整个可用区域，只留 12px 边距，移除原先底部 80px 预留和额外 32px 扣减。放大后内容可跨过原图片的适应边界，占用两侧/上下空白；只在整个预览容器边缘裁显，不修改原始文件或导出尺寸。

平移中心保存在图片的归一化坐标中，继续缩放、收起左栏或调整窗口时维持所看位置；过度拖动有边界保护，“适应”和切换图片恢复完整画面。水印及参考线与图片使用同一图层变换，水印位置仍按原图归一化坐标保存。

新增 5 项几何回归，覆盖 25365×4769、5098×8158 和韩休墓比例图片，完整性、最大适应、跨旧边界放大、平移/缩放中心、窗口变化与拖动边界；合计 60 项通过。TypeScript、桌面编辑器/几何助手 ESLint、Vite 构建及预渲染通过。浏览器验证韩休墓测试图 100%/200%、拖动和复位、竖幅/长卷切换、左栏收起与 1100×760 窗口；默认窗口画布为 1114×626，收起左栏后为 1202×626，均与可用预览区一致。该验证使用完整画面的 2000px 预览素材，不代表新一次原始超大图导出验收。
