# 宋画全集目录

两条路由都通过 `src/app/catalog.ts` 注册，在首页显示并按需加载：

| 入口 | 数据与权限 |
| --- | --- |
| `/song-paintings` | 公共阅读清单。每位新访客默认全部未勾选，只能更改自己的看过／没看过状态。进度保存在当前浏览器，可导入／导出，不写项目 JSON。 |
| `/song-paintings-me` | 个人阅读档案。生产构建展示项目 JSON 内的阅读进度，只读；本地 Vite dev 可勾选及编辑作品信息，直接写回 JSON。 |

## 数据

`catalog.json` 来自既有 Excel 目录，共 1098 条作品：国内版（1、2、3、5 卷）451 条，海外版（4、6、7、8 卷）647 条。每项 `read` 保存个人档案是否看过。作品 `id` 初始为 `卷号-册号-原序号`，后续修正卷册或原序号时保持 ID 不变，以免已有阅读记录失去对应关系。缺失作者或页码保留 `null`。

公共目录只复用作品信息，**不继承个人 `read` 值**。访客进度使用 `song-paintings:visitor:v1` 存储键，与个人 JSON 和旧版 `song-paintings:reading:v1` 隔离。个人 dev 页面提供显式迁移旧版浏览器记录的按钮；不会自动把旧记录当作新访客数据。

目录表将馆藏地放在作品名称后面，随后显示卷号、册号。页码保留在源数据和本地编辑器中。卷册索引按当前目录汇总馆藏地：单馆直接标注，多馆显示概括和展开图标；完整名单支持悬停、键盘聚焦和触屏点击查看，长名单可滚动。

列表不显示原序号；内部编号继续用于作品匹配。手机布局提供吸顶搜索与筛选入口、底部的目录／统计／分享导航，以及作品右侧的大尺寸已读／未读控件。卷册、阅读状态和馆藏名单集中在筛选面板中，点击“查看作品”才应用，关闭会放弃草稿。手机顶栏保留应用入口、个人／公共目录切换及主题按钮，避免悬浮导航遮挡作品。

## 本地编辑与发布

按项目正常方式启动 dev，然后从本机 `localhost` 或 `127.0.0.1` 打开 `/song-paintings-me`。勾选自动保存；每行“编辑”可修正作品名称、作者、年代、馆藏、卷、册及页码。国内／海外分类随卷号更新。也可直接编辑目录 JSON，再返回页面查看。

Vite 插件 `plugins/songCatalog.ts` 只在 dev 注册 `/__song_catalog`。写入校验回环客户端、Host、同源 Origin、会话令牌、请求大小、字段白名单与目录版本，使用临时文件替换。版本冲突拒绝覆盖并提示重试。同一开发服务中的写操作串行执行；若同时使用外部编辑器修改同一 JSON，保存前应完成或关闭其他编辑，避免文件系统级并发覆盖。

生产 build/preview 不注册编辑 API，个人页面不显示勾选控件、编辑和导入入口，也不采用浏览器里的访客或旧版进度。更新个人档案后，随代码重新构建部署即可发布。访客修改自己的浏览器记录或下载副本不会改动发布的个人档案。

## 统计与分享

“阅读统计”根据当前入口的完整目录统计，不受目录搜索或阅读状态筛选影响。包含总阅读环图、国内／海外、各卷、作者、馆藏、年代及卷册进度。分类按收录作品数量排序，默认展示前 8 项，可以展开全部；分子是看过条数，分母是对应分类全部条数。

“生成分享图”将点击时的进度固定为快照，生成 1200×1600 PNG 并预览。弹窗可下拉选择综合、国内版、海外版，默认采用当前目录的版本筛选；统计按完整快照中的所选版本计算，不受搜索、页码或阅读状态筛选影响。海报固定使用檀色纸底，以“宋画全集 · 观画记录”为唯一标题，取消分区线和重复说明，数字使用等高无衬线字体。保留完成率环图、馆藏进度点线图和已看作品年代分布百格图；底部百格图与二维码同尺寸、同水平线排布。

支持下载；浏览器支持文件分享时提供系统分享按钮。切换数据源会重新生成图片，下载和系统分享使用当前选项。右下角二维码在本地编码，透明留白与笺色融合，固定指向 `https://mark.aituring.xyz/song-paintings`，开发环境也使用该公开地址。绘图不依赖外部图片、字体或截图服务。公共清单分享自己的记录，个人档案分享已发布或本地已保存的档案数据；生成图片不修改目录或阅读记录。页面采用暖米笺色、黛青与朱砂点缀，手机保留紧凑尺寸及触控操作区。分享弹窗只保留数据源、预览和操作，关闭与下载按钮保持可见。

## 导入与导出

阅读备份格式为 `{ schemaVersion: 1, catalog: "song-paintings", readIds: string[] }`。导入严格校验作品 ID，并合并已看记录，不清空已有进度；公共页仅写浏览器，个人 dev 页写 JSON。生产个人页仅可导出。

“导出当前目录”包含当前筛选的作品及各自 `read` 值，可供其他工具使用；它与用于恢复状态的阅读记录备份是不同文件。

验证命令：

```sh
node --test scripts/test-song-paintings.mjs scripts/test-song-statistics.mjs scripts/test-song-catalog-api.mjs scripts/test-song-share-data.mjs
```

另需项目 TypeScript 检查、Vite 构建，以及 dev/production 两种运行模式的浏览器验证。
