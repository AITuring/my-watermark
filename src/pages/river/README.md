# 万水 / 水流模拟系统

应用库入口：水流模拟系统。路由保留 `/river`，原小河入口继续有效。

六种水域：小溪（3 × 36 m）、小河（12 × 64 m）、湖泊（460 × 660 m）、大江（180 × 1400 m）、大海、巨浪。环境页设定水深、流量、风速、太阳与清澈度；波浪页设定波高、主周期、方向及浪脊锐度，提供平静到风暴状态；观测页提供时间倍率、低视角/俯瞰、方向箭头与网格。点击水面或使用按钮施加局部扰动，支持暂停、重置、沉浸观景与 PNG 导出。海况预设同时设置 Hs、Tp、风速和浪脊锐度，巨浪风暴为 Hs 18 m / Tp 11.5 s；平静为 Hs 0 / 风速 0 / 锐度 0。切换海况会清除上一状态的白沫、喷雾、扰动、反射缓存与高度回读缓存，暂停状态也能立即切换。

## 实际模型

- 小溪/小河：72 × 216 参考河道交错网格，变水深通量、迎风输运、CFL 子步、反射岸边、吸收两端。物理网格间距按水域尺寸变化。8 个方向扩散的长波分量和细波叠加，长波方差归一化为 Hs²/16，采用有限水深色散；弯曲河道是参考矩形的几何映射。远景河道沿用波列作视觉延伸，不扩大浅水方程求解网格。
- 湖泊/大江/海洋：主风浪、短风浪、斜向长涌浪、交叉浪和短波尾部五组独立随机波谱混合；波群变化控制次级浪系能量占比：最大时长涌浪 22%、交叉浪 10%、短风浪 6%、短波尾部 0.4%，其余为主浪，换一组波群改变可复现的随机种子。三个 256 × 256 方向性 JONSWAP 波谱级联，使用 GPU MRT 蝶形逆 FFT 合成高度和水平位移。海面级联尺度 3072、384、48 m；湖泊为 1024、128、16 m，大江为 2048、256、32 m；基础周期域大于各自的可见水面宽度，减轻远景铺贴重复。频率带不重叠，复高斯种子保持共轭对称，几何波谱对超过主频 4 倍的高频尾部作指数正则化，厘米级风纹独立着色，避免未解算破碎的短波变成米级尖刺；这是渲染模型约束。总方差归一化为 `m0 = Hs²/16`；水平位移随级联尺度降低，避免把长浪锐度直接用于短波造成大面积网格翻折。按 `ω² = (gk + σk³) tanh(kh)` 演化，包含重力、表面张力、有限水深及平均流多普勒平移。局部点击采用衰减径向波包近似。
- 有效波高 Hs 是统计量，个别波峰和峰谷高会不同；附加细波和局部扰动不计入 Hs 归一化。主波相速度 `c = λ/Tp` 与平均输运速度 U 分开。
- 平均河流速度由 `U = Q/A` 计算。小河参考断面面积系数 0.35 + 0.65 × 2/3，大江抛物线参考断面面积系数 0.7；未解算完整稳态背景流场。
- 调整水深、周期或波高时，以 `min(0.45h, 0.09λ tanh(kh))` 限制波高。这是保守的建模约束，并非精确的破浪判据。HS 与 Tp 由使用者独立指定，风速不会自动推导海况。
- 小溪/小河使用线性 HDR 场景缓存和平面场景反射、基于 Snell 定律和实际深度迭代的屏幕空间折射、水深吸收和河床焦散近似。大尺度水域使用 4K 实拍 HDR 天空、精确非偏振水面 Fresnel、Beer 吸收、浪脊透光与 GGX 反光。湖泊和大江还使用岸边场景的 HDR 平面反射，并按真实反射射线校正波面扭曲。长浪场采用四次双线性采样的三次 B 样条重建，避免扩大的纹素形成折面；这种平滑取样会略微衰减高频能量。波面法线来自 FFT 位移场，细波按屏幕足迹过滤；反射射线近似检测波面遮挡并采样上一帧 HDR 场景。线性 HDR 缓冲只在最终输出进行 ACES 色调映射。
- 白沫由长浪和中尺度重力浪的强压缩高浪脊生成，中尺度浪源强度降低到 25%，最短级联不独立产生白沫，以平均流、局部水平位移和 2.5% 风速漂移输运，按 3 秒指数衰减。结合局部浪面梯度、缓变涡动和风向的多尺度片带改变局部朝向与覆盖，仍是视觉近似，未计算空气夹带体积。喷雾粒子采用重力运动，浮标和相机避水使用 GPU 实际高度场回读。岩石、树木、地表使用本地 CC0 扫描模型和材质；岸边草丛同样使用实拍扫描的 21 个草株变体，保留真实尺度；扫描模型保持世界米制比例，森林按 80 m 空间块剔除不可见区域，并对远处针叶使用保留完整针叶岛的 LOD，树枝、针叶和草丛采用根部固定的风场形变，阵风随位置错开相位，摆幅随风速增长；树木阴影在有风时定期更新，无风时缓存，详见 `public/river/ASSETS.md`。

- 小溪与小河的独立漂浮叶片随平均流和风漂移，跟随浅水高度和叠加波列起伏；河床照片中的落叶属于地表材质。植被风吹形变为实时视觉近似，未求解枝干弹性或叶片空气动力学。

## 边界

这是跨尺度实时演示系统，不是完整 CFD、海洋预报或灾害计算软件。未求解三维湍流、真实翻卷破浪、飞溅体积、洪水淹没、岸边完整波反射/折射或河床冲刷。大尺度水面采用线性 FFT 波谱加水平位移，没有求解非线性波波耦合或 SWAN 输运方程；风暴白沫和喷雾发射是视觉近似；粒子虽采用重力轨迹，但不计算水体破裂、空气耦合或水滴体积守恒。湖泊有封闭外观，未计算湖岸驻波和反射。屏幕空间折射只能查询当前视图中的场景，越界时平滑退回近似取样；未求解完整的水下光线路径。

## 验证

```sh
node scripts/test-river-physics.mjs
node scripts/test-water-system.mjs
node scripts/test-spectral-ocean.mjs
npx tsc --noEmit
npx vite build
```

检查浅水扰动的有限性、振幅、固体边界、衰减、净水量、重置，以及六类参数的波谱方差、方向单位化、GPU FFT 蝶形算法与直接 DFT 一致性、共轭对称及逆变换实值性、60 秒采样、深/浅水色散极限、平静状态和波陡约束。

参考：[SWAN 有效波高定义](https://swanmodel.sourceforge.io/online_doc/swanuse/node35.html)、[SWAN 方向性波谱与初始条件](https://swanmodel.sourceforge.io/online_doc/swantech/node64.html)、[NOAA 风浪与浅水传播](https://www.noaa.gov/jetstream/tsunamis/tsunami-propagation/jetstream-max-tsunamis-vs-wind-waves)。

浏览器额外在初始化时比较 GPU 输出与 CPU 直接二维傅里叶求和，结果写入画布容器 `data-wave-validation`；帧率和级联统计分别在 `data-fps`、`data-spectral`；`data-simulation-time` 可验证暂停时间冻结。
